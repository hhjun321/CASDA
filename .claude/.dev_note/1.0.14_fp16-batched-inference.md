# 1.0.14 추론 속도 개선 — fp16 로딩 + num_images_per_prompt 배치화 (5시간 → 1시간)

---

## (사용할 skills: feature-dev)

## 개요

ablation 실험 중 `test_controlnet.py`가 5시간 소요되는 것을 확인. 두 가지 병목이 원인이다.

첫째, 학습은 `mixed_precision: fp16` + `save_fp16: true`로 진행됐으나 추론 시 `torch_dtype=torch.float32`로 로드하여 A100 Tensor Core를 활용하지 못한다. 둘째, `num_images_per_class={"2":10}` 설정에서 `pipeline()`을 10회 순차 호출하여 30 step × 10회 = 300 step이 소요되는 반면, `num_images_per_prompt=10`으로 배치화하면 30 step × 1회로 단축된다. `test_controlnet.py`와 `run_vanilla_sd.py` 두 파일을 함께 개선한다.

---

## 영향도 분석

### 이 기능이 변경하는 상태
- `generate_single()` 반환값 순서: 동일 seed에서 배치 vs 순차 결과가 bit-exact하지 않을 수 있음 (RNG/메모리 레이아웃 차이)
- GPU 메모리 사용 패턴: 배치 크기만큼 peak VRAM 증가 (class 2: ×10)

### 그 상태를 전제로 동작하는 기존 로직
- `generate_from_jsonl()`: `generate_single()` 반환 리스트를 그대로 순회하여 저장 — 리스트 길이가 동일하면 영향 없음
- `run_vanilla_sd.py` resume 로직: sample-level glob check(`{sample_name}_gen*.png`) — 배치화와 무관, 영향 없음

## 수정 내용

### 1. `scripts/test_controlnet.py` — fp16 캐스팅 (4곳)

`load_pipeline()` 내 모든 `torch_dtype=torch.float32`를 `torch.float16`으로 변경.
controlnet과 base pipeline의 dtype이 반드시 일치해야 한다 (불일치 시 forward dtype mismatch 에러).

- pipeline_path 직접 로드 경로 (L142–147)
- ControlNetModel.from_pretrained try 블록 (L175–179)
- ControlNetModel.from_pretrained except safetensors fallback 블록 (L182–187)
- StableDiffusionControlNetPipeline.from_pretrained (L190–195)

### 2. `scripts/test_controlnet.py` — generate_single() 배치화

`for i in range(num_images)` 순차 루프를 `num_images_per_prompt` 배치 호출로 교체.
OOM 발생 시 sequential fallback으로 자동 전환.

```python
# 미사용 변수 제거: L238의 generator = torch.Generator(...).manual_seed(seed) 삭제

generators = [torch.Generator(device=device).manual_seed(seed + i) for i in range(num_images)]
try:
    with torch.autocast(str(device)):
        output = pipeline(
            prompt=prompt, negative_prompt=negative_prompt,
            image=hint_image, height=gen_h, width=gen_w,
            num_inference_steps=num_inference_steps,
            guidance_scale=guidance_scale,
            controlnet_conditioning_scale=controlnet_conditioning_scale,
            generator=generators,
            num_images_per_prompt=num_images,
        )
    results = output.images
except torch.cuda.OutOfMemoryError:
    torch.cuda.empty_cache()
    logger.warning(f"Batch OOM (num_images={num_images}), falling back to sequential")
    results = []
    for i in range(num_images):
        gen = torch.Generator(device=device).manual_seed(seed + i)
        with torch.autocast(str(device)):
            out = pipeline(
                prompt=prompt, negative_prompt=negative_prompt,
                image=hint_image, height=gen_h, width=gen_w,
                num_inference_steps=num_inference_steps,
                guidance_scale=guidance_scale,
                controlnet_conditioning_scale=controlnet_conditioning_scale,
                generator=gen,
            )
        results.append(out.images[0])

if grayscale_postprocess:
    results = [img.convert("L").convert("RGB") for img in results]
return results
```

test_controlnet.py와 동일 패턴 적용. 단 `image=hint_image` 및 `controlnet_conditioning_scale` 파라미터 없음 (text-to-image, ControlNet 없음).
