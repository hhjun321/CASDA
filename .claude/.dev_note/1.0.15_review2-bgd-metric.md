## 개요

Reviewer 2 Comment 9 대응. FID/KID/LPIPS 추가 후에도 "일부 품질 지표에서 CASDA가 Copy-Paste 대비 명확히 우월하지 않다"는 지적이 남아 있다. FID/KID/LPIPS는 분포 수준(distribution-level) 지표로 합성 경계의 자연스러움을 직접 포착하지 못한다.

CASDA의 핵심 차별점인 Poisson blending은 결함-배경 경계의 gradient 불연속성을 평활화한다. Copy-Paste는 hard cut이므로 경계 gradient 불연속성이 크다. `compute_bgd.py`로 각 합성 이미지의 Boundary Gradient Discontinuity(BGD) score를 측정하여 `CASDA(Poisson) < Copy-Paste(hard cut)` 를 정량적으로 입증한다. 기존 `w/o Blending` ablation(1.0.13)과 연계하면 blending 컴포넌트 기여도를 수치로 보강할 수 있다.

논문 활용: "CASDA achieves lower boundary gradient discontinuity (X.X±Y.Y) compared to Copy-Paste (X.X±Y.Y), indicating more natural compositing at defect boundaries."

### 1. `scripts/compute_bgd.py` — 신규 작성

**마스크 소스 (중요)**:
hint R채널 추출 방식은 hint가 512×512 ROI 좌표계라 jitter/scale/위치 증강 후 최종 합성 이미지(1600×256)와 정렬되지 않음. compose 스크립트(`compose_casda_images.py`, `create_copypaste_baseline.py`)가 이미 최종 좌표계에 정렬된 full-size 마스크를 `masks/<name>.png`로 출력하므로 이를 1차 소스로 사용. hint R채널 추출은 `masks/` 없는 경우의 폴백으로만 유지.

**CLI 인자**:
```
--casda-dir      CASDA 합성 이미지 디렉토리 (images/ + masks/ 포함)
--copypaste-dir  Copy-Paste 합성 이미지 디렉토리 (images/ + masks/ 포함)
--hint-dir       hint 이미지 디렉토리 (폴백용, 선택)
--output-dir     결과 저장 디렉토리
--kernel-size    boundary band 폭 (기본 5, band ±2px)
--sample-size    랜덤 샘플 수 (미지정 시 전체)
--seed           샘플링 재현성 (기본 42)
--workers        병렬 처리 수 (기본 4)
```

**BGD 계산 로직**:
```python
def compute_bgd(image_path, mask_path, kernel_size=5):
    image = cv2.imread(image_path)
    mask  = cv2.imread(mask_path, cv2.IMREAD_GRAYSCALE)

    # 해상도 불일치 방어
    if mask.shape != image.shape[:2]:
        mask = cv2.resize(mask, (image.shape[1], image.shape[0]),
                          interpolation=cv2.INTER_NEAREST)

    # binary mask
    _, mask_bin = cv2.threshold(mask, 127, 255, cv2.THRESH_BINARY)

    # boundary band = dilate - erode
    kernel  = cv2.getStructuringElement(cv2.MORPH_ELLIPSE,
                                        (kernel_size*2+1, kernel_size*2+1))
    band    = cv2.dilate(mask_bin, kernel) - cv2.erode(mask_bin, kernel)

    # empty mask/band 방어
    if np.count_nonzero(mask_bin) == 0 or np.count_nonzero(band) == 0:
        return None  # skip, 카운트 로깅

    # gradient magnitude (grayscale)
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY).astype(np.float64)
    gx   = cv2.Sobel(gray, cv2.CV_64F, 1, 0)
    gy   = cv2.Sobel(gray, cv2.CV_64F, 0, 1)
    grad = np.sqrt(gx**2 + gy**2)

    return grad[band > 0].mean()
```

**출력 파일**:
- `bgd_results.json` — 그룹별 mean, std, median, N, per-image score 배열
- `bgd_summary.txt` — 논문 인용용 텍스트 표 (mean±std, N)
- `bgd_boxplot.png` — CASDA vs Copy-Paste boxplot

**공정 비교 보장**: 두 그룹 모두 동일 kernel_size, 동일 Sobel 설정. N 불균형 시 동일 N random subsample 후 비교 (N 원본값도 함께 기록).

**선택적 추가 산출** (코드 포함, 논문 채택은 결과 확인 후):
- 정규화 BGD: 이미지 전체 평균 gradient로 나누어 명암 대비 보정
- Mann–Whitney U p-value
