# 1.0.11 DefectCharacterizer irregular/compact_blob solidity 임계값 분리

---

## (사용할 skills: feature-dev)

## 개요

`DefectCharacterizer.classify_defect_subtype()`에서 `low_solidity` 단일 파라미터가
"irregular 상한"과 "compact_blob 하한" 두 역할을 동시에 담당하는 구조적 결함을 수정한다.
데이터 도출값 `LOW_SOLIDITY=0.9089`(solidity p25)를 `recommended_config.yaml`로 적용하면
`irregular` 경계가 0.70 → 0.9089로 상승해 irregular 405개 → 3,500+으로 폭증한다.
`IRREGULAR_SOLIDITY`를 별도 파라미터로 분리하고, 기본값 0.75로 설정하여
irregular 서브타입을 405 → ~680개로 개선한다.

---

## 영향도 분석

### 이 기능이 변경하는 상태
- `DefectCharacterizer` 분류 기준 변경 → irregular 서브타입 모집단 확장 (~680개)
- `recommended_config.yaml`의 `defect_characterizer_thresholds`에 `IRREGULAR_SOLIDITY` 키 추가
- `threshold_recommendations.json`에 `IRREGULAR_SOLIDITY` 항목 추가

### 그 상태를 전제로 동작하는 기존 로직
- `analyze_dataset.py` 재실행 시 `class_distribution.json`의 `subtype_counts.irregular` 변화
- `subtype_bg_matrix_4x4.json`의 irregular 행 데이터 변경 (샘플 수 증가)
- `recommended_config.yaml:subtype_compatibility_matrix.irregular` 재산출
- `roi_suitability.py:MATCHING_RULES` — 코드 변경 없음, 분류 대상 모집단만 변화

## 결정 사항

### 도출 vs 하드코딩

`IRREGULAR_SOLIDITY` 도출을 위한 후보: "irregular 인스턴스들의 solidity p75"
→ **순환 종속성 문제**: 현재 irregular 인스턴스는 구 경계(0.70) 기준으로 분류된 모집단
(max solidity = 0.6999). 해당 p75 = 0.6751 → 목표값 0.75 도출 불가.

**결론**: `IRREGULAR_SOLIDITY`는 `not_derivable_in_stage0`로 처리, 기본값 0.75 고정.
Stage A 재실행 후 새 모집단 기준 재도출 가능 (향후 과제).

### 1. `src/analysis/defect_characterization.py` — 파라미터 분리 + 분류 로직 변경

**DEFAULT_THRESHOLDS에 추가** (L28 인근):
```python
DEFAULT_THRESHOLDS: dict = {
    'high_linearity':       0.85,
    'high_aspect_ratio':    5.0,
    'low_aspect_ratio':     2.0,
    'high_solidity':        0.9,
    'low_solidity':         0.7,
    'irregular_solidity':   0.75,   # ← 신규: irregular 상한 (low_solidity에서 분리)
}
```

**`__init__` 바인딩 추가** (L44 직후):
```python
self.irregular_solidity = float(t.get('irregular_solidity', d['irregular_solidity']))
```

**`classify_defect_subtype()` 분기 변경** (L234):
```python
# 변경 전
elif solidity < self.low_solidity:
    return 'irregular'

# 변경 후
elif solidity < self.irregular_solidity:
    return 'irregular'
```

⚠️ `compact_blob` 분기(L236)는 `self.high_solidity`를 사용함 — 변경 대상 아님.

**docstring 갱신** (L218):
```python
# 변경 전
'irregular': Low solidity

# 변경 후
'irregular': Low solidity (below irregular_solidity threshold)
```

### 2. `scripts/analyze_dataset.py` — IRREGULAR_SOLIDITY 항목 추가

**HARDCODED dict 추가** (L93-108 인근):
```python
"IRREGULAR_SOLIDITY": 0.75,
```

**threshold_specs에 추가** (elongated_linearity 제거 후 HIGH_LINEARITY 다음):
```python
# (name,                  array,          default, pct,  derivable, use_log_otsu)
("IRREGULAR_SOLIDITY",    np.array([]),    0.75,    75,   False,     False),
```
`derivable=False` — 순환 종속성으로 Stage 0에서 도출 불가. hardcoded 0.75 출력.

**recommended_config.yaml 출력 키 목록 추가** (L1057 인근):
```python
for k in [
    "HIGH_LINEARITY", "HIGH_ASPECT_RATIO", "LOW_ASPECT_RATIO",
    "HIGH_SOLIDITY", "LOW_SOLIDITY", "IRREGULAR_SOLIDITY",   # ← 추가
]
```
