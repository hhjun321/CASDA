## 개요

Reviewer 2의 2차 리뷰 Comment 5(baseline 비교 부족)와 Comment 7(ablation study 미비)에 대응한다.

`baseline_vanilla_sd`는 두 comment를 동시에 충족하는 단일 variant다. Comment 5 관점에서는 generative/diffusion-based baseline이고, Comment 7 관점에서는 ControlNet conditioning 컴포넌트를 제거한 ablation이다.

Comment 7은 1차 rebuttal에서 ablation study를 삭제했던 역효과를 해소하기 위해 기존 2개(w/o Blending, w/o Quality Gate) 외에 3개 신규 컴포넌트 ablation을 추가한다: 호환성 매트릭스 제거(`ablation_no_compat`), context-aware prompt 제거(`ablation_generic_prompt`), 3채널 힌트→1채널 축소(`ablation_1ch_hint`). 최종적으로 5개 ablation + 1개 generative baseline이 포함된 확장 실험 테이블을 구성한다.

## Comment 7 컴포넌트 매핑

| 컴포넌트 | Ablation variant | 대응 Comment |
|---|---|---|
| Compatibility matrix | `ablation_no_compat` | C7 전용 |
| Three-channel hint image | `ablation_1ch_hint` | C7 전용 |
| Prompt construction | `ablation_generic_prompt` | C7 전용 |
| Quality gate | `ablation_no_pruning` (기존) | C7 전용 |
| **ControlNet conditioning** | **`baseline_vanilla_sd`** | **C5 + C7 겸임** |

### 이 기능이 변경하는 상태

### 그 상태를 전제로 동작하는 기존 로직

- `compose_casda_images.py` Step 5 합성 루프: `bg_pool.get_compatible_background()` 호출 지점에 분기 추가, `BackgroundPool.get_random_background()`는 이미 존재

## 수정 내용

### 1. `scripts/test_controlnet.py` — `--generic-prompt` / `--mask-only-hint` 플래그 추가

`parse_args()`에 두 인자 추가:

```python
parser.add_argument(
    "--generic-prompt", type=str, default=None, dest="generic_prompt",
    help="Ablation (w/o Context-Aware Prompt): 모든 샘플에 이 generic prompt를 사용.",
)
parser.add_argument(
    "--mask-only-hint", action="store_true", default=False, dest="mask_only_hint",
    help="Ablation (w/o 3-channel Hint): hint 이미지의 G/B 채널을 0으로 설정.",
)
```

`apply_mask_only_hint()` 헬퍼 함수 추가 (모듈 상단):

```python
def apply_mask_only_hint(hint_image: Image.Image) -> Image.Image:
    arr = np.array(hint_image.convert("RGB"))
    arr[:, :, 1] = 0  # G=0
    arr[:, :, 2] = 0  # B=0
    return Image.fromarray(arr)
```

`generate_from_jsonl()` 루프 내 hint 로드 직후에 플래그 적용:

```python
if args.generic_prompt:
    prompt = args.generic_prompt

if args.mask_only_hint:
    hint_image = apply_mask_only_hint(hint_image)
```

### 2. `scripts/compose_casda_images.py` — `--no-compatibility` 플래그 추가

`main()` argparse에 플래그 추가:

```python
parser.add_argument(
    "--no-compatibility", action="store_true", default=False, dest="no_compatibility",
    help="Ablation (w/o Compatibility Matrix): 호환성 매트릭스 무시, 완전 랜덤 배경 선택.",
)
```

`compose_all()` 함수 시그니처에 `no_compat: bool = False` 파라미터 추가. Step 5 합성 루프의 배경 선택 분기:

```python
for comp_idx in range(compositions_per_roi):
    if no_compat:
        bg_name = bg_pool.get_random_background(rng=rng)
    else:
        bg_name = bg_pool.get_compatible_background(
            defect_subtype=defect_subtype,
            roi_x_center=roi_x_center,
            target_brightness=target_brightness,
            brightness_tolerance=brightness_tolerance,
            rng=rng,
        )
```

`main()`에서 `compose_all()` 호출 시 `no_compat=args.no_compatibility` 전달.

### 3. `scripts/run_vanilla_sd.py` (신규) — SD text-to-image baseline 생성 스크립트

`StableDiffusionPipeline`으로 ControlNet 없이 text-to-image 생성. 입출력 인터페이스는 `test_controlnet.py`와 동일하게 유지 (compose 파이프라인 재사용을 위해):
- 입력: `--jsonl_path` (train.jsonl, prompt만 사용), `--output_dir`
- 출력: `output_dir/generated/*.png` + `output_dir/generation_summary.json`
- `generation_summary.json`의 각 result에 `hint_path` 필드 포함 (원본 CN_DATASET/hints 경로 참조, compose 단계의 마스크 추출에 필요)
- grayscale 후처리 동일 적용 (SD v1.5 VAE RGB 아티팩트 제거)
- `--num_images_per_class` 파라미터 동일하게 지원
- hint 이미지를 conditioning에 사용하지 않으므로 `image=` 인자 없이 `pipeline(prompt=...)` 호출
