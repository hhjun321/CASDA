## 개요

`analyze_dataset.py`의 임계값 도출 로직이 Otsu 단일값으로 HIGH/LOW 쌍을 동시에 생성하여
`LOW_ASPECT_RATIO = HIGH_ASPECT_RATIO = 8.2034` 동일값 버그가 발생했다.
DefectCharacterizer의 `aspect_ratio > HIGH` (elongated), `aspect_ratio < LOW` (compact_blob) 분류가
두 값이 같으면 compact_blob을 판별 불가능하다.

추가로 Stage 0 결과 기반으로 배경 타입(5종 → 4종 또는 3종)과 결함 서브타입(4종 → 3종) 축소 여부를
데이터로 검증해야 한다. `variance_threshold 100→14`, `total_strength 1→49.5` 등 새 임계값 적용 후
배경 재분류 결과가 바뀌므로 타입 구조 결정 전 재검증이 필수다.

### 1. `scripts/analyze_dataset.py` — HIGH/LOW 임계값 분리 도출

**현재 버그**: `derive_threshold()` 가 모든 파라미터에 동일 로직 적용 → HIGH/LOW가 같은 배열의 같은 Otsu값

현재:
```python
# 버그 — 동일 배열, 동일 메서드 → 동일값
HIGH_ASPECT_RATIO = derive_threshold(aspect_ratios, 'otsu_1d')  # 8.2034
LOW_ASPECT_RATIO  = derive_threshold(aspect_ratios, 'otsu_1d')  # 8.2034
```

**교체 방향**:

| 파라미터 | HIGH | LOW | 방법 근거 |
|---------|------|-----|---------|
| LINEARITY | GMM K=2, upper boundary | GMM K=2, lower boundary | 0~0.5 군집 + 0.9~1.0 군집 명확 |
| ASPECT_RATIO | P80 | P20 | 롱테일 우편향 — GMM 불안정 |
| SOLIDITY | P80 | P20 | 0.8~1.0 집중, valley 없음 |

```python
from sklearn.mixture import GaussianMixture
import numpy as np

MIN_SAMPLES_GMM = 500  # TODO: 확정 필요

def derive_gmm_boundaries(values):
    """GMM K=2 — (lower_boundary, upper_boundary) 반환"""
    gmm = GaussianMixture(n_components=2, random_state=42)
    gmm.fit(values.reshape(-1, 1))
    means = sorted(gmm.means_.flatten())
    stds = [gmm.covariances_[i][0][0] ** 0.5 for i in range(2)]
    lower_boundary = means[0] + stds[0]
    upper_boundary = means[1] - stds[1]
    return lower_boundary, upper_boundary

def derive_high_low(values, method):
    """(HIGH, LOW) 반환 — 항상 HIGH > LOW 보장"""
    if method == 'gmm' and len(values) >= MIN_SAMPLES_GMM:
        low, high = derive_gmm_boundaries(values)
    else:
        high = float(np.percentile(values, 80))
        low  = float(np.percentile(values, 20))
    assert high > low, f"HIGH/LOW 역전: {high} <= {low}"
    return high, low

# 호출부 교체
high_lin, low_lin = derive_high_low(linearity_arr, 'gmm')
high_ar,  low_ar  = derive_high_low(aspect_ratio_arr, 'percentile')
high_sol, low_sol = derive_high_low(solidity_arr, 'percentile')
```

### 2. 서브타입별 임계값 분리 (선택적 확장)

현재 전체 19,958개 합산 → 단일 임계값. 개선: 서브타입별 별도 도출.

```python
PER_SUBTYPE_MIN = 500  # irregular(405) 미달 → percentile fallback

per_subtype_thresholds = {}
for subtype in ['linear_scratch', 'compact_blob', 'general', 'irregular']:
    subset = morph_df[morph_df['defect_subtype'] == subtype]['linearity'].values
    method = 'gmm' if len(subset) >= PER_SUBTYPE_MIN else 'percentile'
    high, low = derive_high_low(subset, method)
    per_subtype_thresholds[subtype] = {
        'HIGH_LINEARITY': high, 'LOW_LINEARITY': low, 'method': method
    }
```

**Step 3 — 결함 서브타입 GMM 클러스터링**
```python
import pandas as pd
import numpy as np
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

morph_df = pd.read_csv(f"{os.environ['ANALYSIS_DIR']}/morphological_features.csv")
features = morph_df[['linearity', 'aspect_ratio', 'solidity']].dropna()
X = StandardScaler().fit_transform(features)

scores, bics = {}, {}
for k in [2, 3, 4]:
    gmm = GaussianMixture(n_components=k, random_state=42, n_init=5)
    labels = gmm.fit_predict(X)
    scores[k] = silhouette_score(X, labels)
    bics[k]   = gmm.bic(X)
    print(f"K={k}: silhouette={scores[k]:.4f}, BIC={bics[k]:.1f}")

best_k = max(scores, key=scores.get)
print(f"\n[판단 3] 최적 K={best_k}")
print("→ 3종 확정 (irregular → general 흡수 권장)" if best_k <= 3
      else "→ 4종 유지 검토")

# 시각화 저장
gmm_final = GaussianMixture(n_components=best_k, random_state=42).fit(X)
labels = gmm_final.predict(X)
fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(features['linearity'], features['aspect_ratio'],
                     c=labels, cmap='tab10', alpha=0.5, s=10)
ax.set_xlabel('linearity'); ax.set_ylabel('aspect_ratio')
ax.set_title(f'Subtype GMM Clustering (K={best_k})')
plt.colorbar(scatter)
plt.tight_layout()
plt.savefig(f"{os.environ['ANALYSIS_DIR']}/figures/fig11_gmm_subtype_clusters.png", dpi=120)
print("저장: figures/fig11_gmm_subtype_clusters.png")
```
