# 1.0.1 Stage A — 데이터 기반 임계값 동적 적용

---

## (사용할 skills: feature-dev)

## 개요

Stage 0(`analyze_dataset.py`) 실행 후 생성된 `recommended_config.yaml`을 Stage A 스크립트들이 읽어 하드코딩된 19개 임계값을 동적으로 적용하도록 변경한다. 현재 모든 임계값이 코드 내에 상수로 박혀 있어 데이터 기반 조정이 불가능하다.

---

## 영향도 분석

### 이 기능이 변경하는 상태
- `DefectCharacterizer.classify_defect_subtype()` 내부 임계값 상수 → 생성자/인자로 외부화
- `BackgroundAnalyzer.__init__()` 인자 확장 (stripe_ratio_v/h, total_strength, high_freq_ratio 추가)
- `BackgroundAnalyzer.classify_patch()` 내부 하드코딩 상수 → 인스턴스 변수로 교체
- `extract_rois.py`, `prepare_controlnet_data.py` CLI: `--config` 인자 추가

### 그 상태를 전제로 동작하는 기존 로직
- `roi_extraction.py`: `DefectCharacterizer`, `BackgroundAnalyzer` 인스턴스 생성 → 생성자 시그니처 변경 시 수정 필요
- `extract_rois.py`: `BackgroundAnalyzer(grid_size, variance_threshold=100.0, edge_threshold=0.3)` 고정값 전달 → `recommended_config.yaml` 읽어 전달

## 수정 내용

### 1. `src/analysis/defect_characterization.py` — 임계값 외부화

`classify_defect_subtype()` 내부 상수를 인스턴스 변수로 이동:
```python
class DefectCharacterizer:
    def __init__(self,
                 high_linearity=0.85, high_aspect_ratio=5.0,
                 low_aspect_ratio=2.0, high_solidity=0.9,
                 low_solidity=0.7, elongated_linearity=0.6):
        self.HIGH_LINEARITY      = high_linearity
        self.HIGH_ASPECT_RATIO   = high_aspect_ratio
        self.LOW_ASPECT_RATIO    = low_aspect_ratio
        self.HIGH_SOLIDITY       = high_solidity
        self.LOW_SOLIDITY        = low_solidity
        self.ELONGATED_LINEARITY = elongated_linearity
```
`classify_defect_subtype()`에서 상수 대신 `self.*` 참조.

### 2. `src/analysis/background_characterization.py` — 임계값 외부화

`BackgroundAnalyzer.__init__()` 인자 추가:
```python
def __init__(self, grid_size=64, variance_threshold=100.0,
             edge_threshold=0.3, total_strength=1.0,
             stripe_ratio=1.5, high_freq_ratio=0.3):
    ...
    self.total_strength  = total_strength
    self.stripe_ratio    = stripe_ratio
    self.high_freq_ratio_threshold = high_freq_ratio
```
`classify_patch()` 내부 하드코딩 → `self.*` 참조 교체:
- `if variance < self.variance_threshold`
- `if total_strength < self.total_strength`
- `if v_ratio > self.edge_threshold and v_ratio > h_ratio * self.stripe_ratio`
- `if freq_info['high_freq_ratio'] > self.high_freq_ratio_threshold`

### 3. `src/preprocessing/roi_extraction.py` — 생성자 전달

`ROIExtractor.__init__()`에서 `DefectCharacterizer`, `BackgroundAnalyzer` 인스턴스 생성 시 기본값 유지 (하위 호환).

### 4. `scripts/extract_rois.py` — `--config` 인자 추가

```bash
python scripts/extract_rois.py \
  --image_dir ... --train_csv ... --output_dir ... \
  --config /path/to/recommended_config.yaml  # 생략 시 기존 기본값 유지
```

`recommended_config.yaml` 로드 후:
```python
dc_cfg = config.get('defect_characterizer_thresholds', {})
bg_cfg = config.get('background_analyzer_thresholds', {})
defect_analyzer   = DefectCharacterizer(**dc_cfg)
background_analyzer = BackgroundAnalyzer(grid_size=args.grid_size, **bg_cfg)
```

### 5. `scripts/prepare_controlnet_data.py` — `--config` 인자 추가

`per_class_cap`, `rare_class_threshold`를 `recommended_config.yaml`의 `pipeline_parameters`에서 읽어 적용.
