# 1.0.6 선택 편향 수정 — run_split_experiment.py val_metrics 기준 변경

---

## (사용할 skills: micro-fix)

## 개요

`run_split_experiment.py`에서 split 비율(70/15/15) 선택 기준이 현재 test Dice이다. 리뷰어 지적대로 이는 선택 편향(Selection Bias)에 해당한다. split 비율 선택 기준을 val Dice로 변경하여 test set을 최종 보고에서만 사용하도록 수정한다.

---

## 영향도 분석

### 이 기능이 변경하는 상태
- `collect_results()` 반환 dict: `val_best_metric` 필드 추가
- `compare_splits()`의 `best_split` 선택 기준: `dice_mean`(test) → `val_best_metric`(val)

### 그 상태를 전제로 동작하는 기존 로직
- split 비교 테이블 출력(`print_split_table()`): `val_best_metric` 컬럼 추가 필요
- 결과 JSON(`split_comparison.json`): `best_split`, `best_dice` 필드 — `best_val_metric` 필드 추가

---

## 수정 내용

### 1. `scripts/run_split_experiment.py:collect_results()` — `val_best_metric` 추가

현재 (`run_split_experiment.py:316-344`):
```python
metrics = seg_result.get('test_metrics', seg_result.get('metrics', {}))
return {
    'label': label,
    'dice_mean': metrics.get('dice_mean', 0.0),
    ...
}
```

수정:
```python
# benchmark_results.json의 'best_metric' = val Dice at best epoch
# (trainer.py:434에서 val_loader 기준으로 갱신됨)
val_best = seg_result.get('best_metric', 0.0)

return {
    'label': label,
    'dice_mean': metrics.get('dice_mean', 0.0),      # test Dice (보고용)
    'val_best_metric': val_best,                      # val Dice (선택용) ← 추가
    ...
}
```

### 2. `scripts/run_split_experiment.py:compare_splits()` — 선택 기준 변경

현재 (`run_split_experiment.py:370-374`):
```python
if results:
    best = max(results, key=lambda r: r.get('dice_mean', 0.0))
    report['best_split'] = best['label']
    report['best_dice'] = best['dice_mean']
```

수정:
```python
if results:
    best = max(results, key=lambda r: r.get('val_best_metric', 0.0))
    report['best_split']       = best['label']
    report['best_val_metric']  = best['val_best_metric']  # val 기준 best
    report['best_test_dice']   = best['dice_mean']         # 참고용 test Dice
```

### 3. 출력 테이블 컬럼 추가 (`run_split_experiment.py:print_split_table()` 부근)

```
Split    | Train | Val | Test | val_Dice | test_Dice | best_epoch
70/15/15 |  ...  | ... | ...  |  0.7821  |   0.7654  |     42
★ Best split (val 기준): 70/15/15 → val_Dice=0.7821
```
