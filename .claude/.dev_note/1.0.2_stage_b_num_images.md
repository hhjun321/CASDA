## 개요

`test_controlnet.py`의 `--num_images_per_class` 파라미터가 현재 `{"1":2,"2":10,"3":1,"4":2}`로 하드코딩되어 있다. Stage 0의 `recommended_config.yaml`에서 데이터 기반 값을 읽어 자동 적용하도록 변경한다.

---

## 영향도 분석

### 이 기능이 변경하는 상태
- `test_controlnet.py` CLI: `--config` 인자 추가
- `--num_images_per_class`의 기본 소스가 하드코딩 → YAML 파일로 변경

### 그 상태를 전제로 동작하는 기존 로직
- QUICKSTART.md의 실행 명령 (문서 업데이트 필요)
- 기존 실행 시 `--num_images_per_class` 명시 전달한 경우 → CLI 인자 우선 (하위 호환)

## 수정 내용

### 1. `scripts/test_controlnet.py` — `--config` 인자 추가

```python
parser.add_argument(
    '--config', type=str, default=None,
    help='Path to recommended_config.yaml from Stage 0 analysis'
)
```

로드 로직:
```python
if args.config and Path(args.config).exists():
    import yaml
    with open(args.config) as f:
        cfg = yaml.safe_load(f)
    # CLI --num_images_per_class 미지정 시 config 값 사용
    if args.num_images_per_class is None:
        num_map = cfg.get('pipeline_parameters', {}).get('num_images_per_class', {})
        if num_map:
            args.num_images_per_class = json.dumps({str(k): v for k, v in num_map.items()})
```
