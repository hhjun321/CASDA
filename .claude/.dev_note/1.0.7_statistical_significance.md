# 1.0.7 통계적 유의성 확보 — 3 random seed 반복 실험

---

## (사용할 skills: feature-dev)

## 개요

현재 모든 실험이 seed=42 단일 실행이다. 0.3~1pp 수준의 성능 차이는 통계적으로 무의미하다. `run_benchmark.py`에 multi-seed 반복 실험 지원을 추가하여 mean ± std를 보고할 수 있도록 한다.

---

## 영향도 분석

### 이 기능이 변경하는 상태
- `run_benchmark.py`: `--seeds` 인자 추가
- `benchmark_experiment.yaml`: `seeds` 설정 추가
- 출력 `benchmark_results.json`: seed별 결과 + 집계 통계 구조로 확장
- 총 실험 비용: 현재 대비 3× (27+ GPU run 추가)

### 그 상태를 전제로 동작하는 기존 로직
- 가설 검정 (`H3~H6`): 단일 결과 기준 → mean 기준으로 변경 필요
- `run_analysis.py` (결과 분석): seed 집계 로직 추가 필요

## 수정 내용

### 1. `scripts/run_benchmark.py` — `--seeds` 인자 추가

```python
parser.add_argument('--seeds', type=int, nargs='+', default=[42],
                    help='Random seeds to run (default: [42]). '
                         'Example: --seeds 42 123 456')
```

내부 반복:
```python
all_seed_results = []
for seed in args.seeds:
    # 각 seed로 동일 실험 재실행
    seed_result = run_single_experiment(
        model_key=model_key,
        dataset_group=dataset_group,
        config=config,
        seed=seed,
        ...
    )
    all_seed_results.append({'seed': seed, 'metrics': seed_result})

# seed 집계
if len(all_seed_results) > 1:
    dice_values = [r['metrics']['dice_mean'] for r in all_seed_results]
    aggregated = {
        'mean': float(np.mean(dice_values)),
        'std':  float(np.std(dice_values)),
        'seeds': all_seed_results,
    }
```

### 2. `configs/benchmark_experiment.yaml` — seeds 설정 추가

```yaml
experiment:
  seeds: [42, 123, 456]   # 통계적 유의성을 위한 3 seed
  # seeds: [42]            # 단일 실행 (기존 동작)
```

### 3. `benchmark_results.json` 출력 구조 확장

```json
{
  "model": "yolo_mfd",
  "dataset": "casda_composed_pruning",
  "seeds": [42, 123, 456],
  "per_seed": [
    {"seed": 42,  "test_metrics": {"mAP@0.5": 0.712}},
    {"seed": 123, "test_metrics": {"mAP@0.5": 0.708}},
    {"seed": 456, "test_metrics": {"mAP@0.5": 0.715}}
  ],
  "aggregate": {
    "mAP@0.5_mean": 0.712,
    "mAP@0.5_std":  0.004
  }
}
```

### 4. 가설 검정 결과 업데이트

`H3~H6` 검정에서 단일 결과 대신 mean ± std 기반 통계 검정(t-test 또는 Wilcoxon) 적용:
- seed 3개는 t-test에 부족 → 95% CI 또는 effect size 보고
- 또는 seed 5개로 확장 검토
