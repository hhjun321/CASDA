# 1.0.5 합성 비율 체계적 탐색 (synthetic_ratio grid search)

---

## (사용할 skills: feature-dev)

## 개요

현재 `top_k=2500` (≈42.7%)이 근거 없이 하드코딩되어 있다. 리뷰어 질의("최적 합성 비율은 어떻게 결정되었나?")에 대응하기 위해 synthetic_ratio grid search를 구현하여 비율별 val Dice 곡선과 train/val loss gap을 제시한다.

## 수정 내용

### 1. 신규 스크립트 `scripts/run_ratio_search.py`

기존 `run_benchmark.py`의 inject/train 패턴을 재사용. DeepLabV3+ 단독으로 ratio별 실험:

```
ratio 탐색 범위: 10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60, 65, 70 (%)
각 ratio × 3 seed → val Dice + train/val loss gap 측정
총 13 × 3 = 39 run
```

```python
for ratio in range(10, 75, 5):
    for seed in [42, 123, 456]:
        # ratio에 해당하는 top_k 계산
        total_train = len(baseline_raw_train_ids)
        top_k = int(total_train * ratio / (100 - ratio))

        # inject top_k CASDA images (stratified)
        inject_casda_to_baseline(baseline_dir, casda_dir,
                                  max_samples=top_k, stratified=True)
        # train DeepLabV3+ (100 epochs)
        # collect val_best_metric, train/val loss history
        clean_casda_from_baseline(baseline_dir)
```

### 2. 출력

```
ratio_search_results.json:
  [
    {"ratio": 10, "seed": 42, "val_dice": ..., "train_val_gap": ...},
    ...
  ]

ratio_search_plot.png:
  - x축: synthetic ratio (%)
  - y축: val Dice (mean ± std across seeds)
  - 보조 y축: train/val loss gap (overfitting 지표)
```

### 3. `benchmark_experiment.yaml` 설정 추가

```yaml
ratio_search:
  enabled: false
  ratios: [10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60, 65, 70]
  seeds: [42, 123, 456]
  model: "deeplabv3plus"
  epochs: 100
  output_dir: "${DRIVE_DATA}/ratio_search"
```
