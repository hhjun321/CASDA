## 개요

Stage A (extract_rois.py) 실행 결과 서브타입 분포가 Stage 0 분석 대비 역전됨:
- linear_scratch 41% → 3.8%, compact_blob 23.8% → 3.2%, general 31.7% → 87.1%

원인: `analyze_dataset.py`의 `derive_high_low()`가 **percentile 전용** 함수로,
우편향 분포(aspect_ratio, solidity)에서 `hi_pct=90 → p90`을 정규 출력으로 반환.
p90은 극단값 경계라 LINEAR_SCRATCH 정의를 상위 10%로 제한, COMPACT_BLOB도 상위 10%로 제한.

**수정 목표:**
- HIGH_ASPECT_RATIO: `log_otsu` 적용 (AR 분포 bimodal split → 기대값 ~5~7)
- HIGH_SOLIDITY: `hi_pct=25` (p25 ≈ 0.91 → 원래 하드코딩 0.9와 유사)

Stage A 재실행 시 linear_scratch ~40%, compact_blob ~20% 회복 기대.

## 수정 내용

### 1. `scripts/analyze_dataset.py` — `derive_high_low()` 함수 확장

`use_log_otsu_high: bool = False` 파라미터 추가. high_v 도출에만 적용:

```python
def derive_high_low(
    values: np.ndarray,
    high_default: float,
    low_default: float,
    high_pct: int = 90,
    low_pct: int = 25,
    use_log_otsu_high: bool = False,   # ← 신규
) -> tuple:
    """
    HIGH/LOW 임계값을 분리 도출.
    use_log_otsu_high=True: high_v를 log_otsu로 먼저 시도, 실패 시 percentile(high_pct) fallback.
    """
    finite = values[np.isfinite(values)] if len(values) else values
    if len(finite) < 50:
        return (
            (high_default, "hardcoded(insufficient_n)"),
            (low_default,  "hardcoded(insufficient_n)"),
        )

    # high_v 도출
    if use_log_otsu_high:
        lo_val = _log_otsu(finite)
        if lo_val is not None:
            high_v = lo_val
            high_m = "log_otsu"
        else:
            high_v = float(np.percentile(finite, high_pct))
            high_m = f"p{high_pct}"
    else:
        high_v = float(np.percentile(finite, high_pct))
        high_m = f"p{high_pct}"

    low_v = float(np.percentile(finite, low_pct))

    if not (high_v > low_v):
        return (
            (high_default, "hardcoded(degenerate)"),
            (low_default,  "hardcoded(degenerate)"),
        )

    return (round(high_v, 4), high_m), (round(low_v, 4), f"p{low_pct}")
```

`_log_otsu()`는 이미 동일 파일에 정의됨 (1.0.9에서 추가). 호출 가능.

### 2. `scripts/analyze_dataset.py` — `pair_specs` 수정

```python
pair_specs = [
    # (hi_name, lo_name, array, hd_hi, hd_lo, hi_pct, lo_pct, use_log_otsu_high)
    ("HIGH_ASPECT_RATIO", "LOW_ASPECT_RATIO", arr["aspect_ratio"], 5.0, 2.0, 90, 25, True),
    # use_log_otsu_high=True: log_otsu로 bimodal split 시도 → 기대 ~5~7
    # log_otsu 실패 시 p90 fallback (기존 동작 유지)

    ("HIGH_SOLIDITY",     "LOW_SOLIDITY",     arr["solidity"],     0.9, 0.7, 25,  5, False),
    # hi_pct 90→25: p25 of solidity ≈ 0.91 (원래 하드코딩 0.9에 근접)
    # lo_pct 25→5: p5 ≈ 0.58 (degenerate 방지, LOW_SOLIDITY는 현재 분류 미사용)
]
```
