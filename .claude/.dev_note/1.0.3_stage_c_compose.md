## 수정 내용

### 1. `scripts/compose_casda_images.py` — `--config` 인자 + 매트릭스 로드

```python
parser.add_argument('--config', type=str, default=None,
                    help='Path to recommended_config.yaml from Stage 0')
```

COMPATIBILITY_MATRIX 덮어쓰기:
```python
if args.config and Path(args.config).exists():
    cfg = yaml.safe_load(open(args.config))
    compat = cfg.get('pipeline_parameters', {}).get('compatibility_matrix', {})
    if compat:
        # compat: {class_id_str: {bg_type: score}} → subtype 기반으로 변환
        # class별 dominant subtype 기반으로 COMPATIBILITY_MATRIX 재구성
        _apply_config_compatibility(compat)
    comp_per_roi = cfg.get('pipeline_parameters', {}).get('compositions_per_roi', args.compositions_per_roi)
    args.compositions_per_roi = comp_per_roi
```

**주의**: 기존 `COMPATIBILITY_MATRIX`는 `defect_subtype → bg_type → score` 구조. `recommended_config.yaml`의 `compatibility_matrix`는 `class_id → bg_type → score` 구조. 변환 헬퍼 `_apply_config_compatibility()` 필요.

### 2. `scripts/validate_augmented_quality.py` — `--config` 인자

```python
if args.config:
    cfg = yaml.safe_load(open(args.config))
    min_q = cfg.get('pipeline_parameters', {}).get('min_quality_score')
    if min_q is not None and args.min_quality_score == 0.7:  # 기본값일 때만 덮어쓰기
        args.min_quality_score = min_q
```
