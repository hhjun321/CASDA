## 개요

`run_fid.py`에서 현재 FID만 계산하는 것을 확장하여 KID, LPIPS, Mask-to-defect alignment (IoU)를 추가로 계산한다. 각 지표의 목적:
- **KID**: 소규모 데이터셋에서 FID보다 분산 안정적 (unbiased estimator)
- **LPIPS**: image-pair 수준 perceptual similarity (생성 이미지 ↔ 원본 ROI)
- **Mask-IoU**: GT mask(hint R채널) ↔ 생성 이미지 실제 결함 위치 일치도 — 어노테이션 품질 검증

### 2. `scripts/run_fid.py` — LPIPS 추가

image-pair 수준 측정 (생성 이미지 ↔ 해당 ROI 원본):
```python
import lpips
loss_fn = lpips.LPIPS(net='alex').cuda()

# 생성 이미지와 대응 원본 ROI 쌍 구성 (metadata.json의 source_generated 필드 활용)
lpips_scores = []
for gen_img, ref_img in matched_pairs:
    score = loss_fn(gen_tensor, ref_tensor)
    lpips_scores.append(float(score))
lpips_mean = float(np.mean(lpips_scores))
```

**주의**: LPIPS는 이미지 쌍이 필요. `generation_summary.json`의 `hint_path`와 생성 이미지를 쌍으로 구성.

### 3. `scripts/run_fid.py` — Mask-IoU 추가

GT mask (hint R채널) ↔ 생성 이미지 결함 탐지 영역 IoU:
```python
def compute_mask_iou(hint_path, generated_path, threshold=127):
    hint = cv2.imread(str(hint_path))
    gt_mask = (hint[:, :, 0] > threshold).astype(np.uint8)  # R채널

    gen = cv2.imread(str(generated_path), cv2.IMREAD_GRAYSCALE)
    # 생성 이미지에서 결함 영역 추정: Otsu thresholding 또는 edge 기반
    _, pred_mask = cv2.threshold(gen, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    pred_mask = (pred_mask > 0).astype(np.uint8)

    intersection = (gt_mask & pred_mask).sum()
    union = (gt_mask | pred_mask).sum()
    return float(intersection / union) if union > 0 else 0.0
```

**주의**: Mask-IoU는 생성 이미지에서 결함 위치 자동 추정이 필요. Otsu 방식의 한계 인지 필요 — 완벽한 정량화보다 상대적 비교 지표로 활용.
