## 개요

`run_fid.py`에서 현재 FID만 계산하는 것을 확장하여 KID를 추가로 계산한다.

- **KID**: 소규모 데이터셋에서 FID보다 분산 안정적 (unbiased estimator). 논문 비교용으로 FID와 함께 보고.

> LPIPS 제외: ControlNet은 픽셀 텍스처가 아닌 hint 구조에 conditioning되므로 쌍 단위 유사도 비교가 의미 없음.
> Mask-IoU 제외: paste 좌표가 곧 어노테이션이므로 위치 일치도는 파이프라인 구조상 항상 보장됨.

## 수정 내용

### 1. `scripts/run_fid.py` — torch-fidelity로 FID + KID 통합 계산

`torch-fidelity`는 FID와 KID를 동일한 InceptionV3 피처 추출 패스에서 함께 계산한다. 기존 FID 계산 로직을 대체한다.

```python
from torch_fidelity import calculate_metrics

metrics = calculate_metrics(
    input1=real_dir,
    input2=generated_dir,
    cuda=True,
    fid=True,
    kid=True,
    kid_subset_size=min(n_real, 1000),  # 소규모 데이터셋 대응
    verbose=False,
)
# metrics['frechet_inception_distance']     → FID
# metrics['kernel_inception_distance_mean'] → KID mean
# metrics['kernel_inception_distance_std']  → KID std
```

**주의**: 기존 FID 계산 방식(직접 구현 또는 pytorch-fid)과 수치가 미세하게 다를 수 있음. 동일 이미지셋 기준으로 회귀 검증 필요.
