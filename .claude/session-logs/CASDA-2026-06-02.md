## Otsu가 틀린 이유

Otsu는 **단일 이분 임계값** 탐색 — 클래스 간 분산 최대화 지점 하나만 반환.

`HIGH_ASPECT_RATIO`와 `LOW_ASPECT_RATIO`를 같은 Otsu에서 뽑으면 → **8.2034 = 8.2034** (증거 완료).  
DefectCharacterizer 로직 `aspect_ratio > HIGH` → elongated, `aspect_ratio < LOW` → compact_blob 에서 HIGH == LOW이면 compact_blob 분류 불가능.

**Otsu가 맞는 경우**: 배경 마스킹처럼 진짜 bimodal 분포에서 경계 하나가 필요한 경우. 형태학적 특성은 해당 없음.

## 히스토그램으로 본 각 피처의 실제 분포

fig3 기준:

| 피처 | 분포 형태 | Otsu 적합? |
|-----|----------|-----------|
| linearity | 0~0.5 저밀도 + 0.9~1.0 스파이크 | 어느정도. 그래도 bimodal 가정 취약 |
| aspect_ratio | 1~5 밀집 + 80+ 극단 롱테일 | **부적합** — 우편향 극심 |
| solidity | 0.8~1.0 집중 | **부적합** — HIGH/LOW 구분 불가 |
| extent | 0.6~1.0 완만한 단봉 | 부적합 |

## 방법별 비교

### Percentile

```python
LOW_threshold  = np.percentile(values, 20)   # P20 — 하위 20%
HIGH_threshold = np.percentile(values, 80)   # P80 — 상위 20%
```

**장점**: 분포 가정 없음, 구현 단순, 항상 LOW < HIGH 보장  
**단점**: 자연적 클러스터 경계를 모름 — 단순 분위 절단  
**적합**: aspect_ratio(롱테일), extent(완만 단봉)

---

### GMM (Gaussian Mixture Model)

```python
from sklearn.mixture import GaussianMixture

gmm = GaussianMixture(n_components=2, random_state=0)
gmm.fit(values.reshape(-1, 1))

# 두 가우시안 평균 정렬
means = sorted(gmm.means_.flatten())
# 두 컴포넌트 경계: 두 평균 사이 교차점
# LOW = lower_gaussian의 mean + std
# HIGH = upper_gaussian의 mean - std
```

**장점**: 실제 데이터 군집 경계 탐지, bimodal 구조 활용  
**단점**: n_components 사전 지정, 샘플 부족 시 불안정 (`irregular` 405개 — 경계선)  
**적합**: linearity (0 근처 군집 + 1.0 근처 군집 명확), solidity (유사 구조)

## 각 파라미터별 권장 방법

| 파라미터 | 권장 방법 | 이유 |
|---------|---------|------|
| HIGH_LINEARITY | **GMM** K=2, upper boundary | 두 군집 명확 (비선형 vs 선형) |
| LOW_LINEARITY | **GMM** K=2, lower boundary | 동일 |
| HIGH_ASPECT_RATIO | **Percentile P80** | 롱테일, GMM 불안정 |
| LOW_ASPECT_RATIO | **Percentile P25** | 동일, P25 ≈ compact 영역 |
| HIGH_SOLIDITY | **GMM** K=2, upper cluster mean | 고솔리디티 군집 존재 |
| LOW_SOLIDITY | **Percentile P20** or **GMM** lower | 저솔리디티 샘플 수 부족 고려 |
